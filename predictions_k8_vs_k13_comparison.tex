\section*{Assessment}
\begin{itemize}
  \item \textbf{Point CGCNN (primary goal):} validation $R_{\mathrm{tot}}$ median 27.48\% $\rightarrow$ 34.79\% (+7.3~pp). Net-energy generalization \textbf{did not improve} on held-out validation despite $k=13$ and full-cell training loss; checkpoint metric changed (graph $\rightarrow$ full).
  \item \textbf{Point Transformer:} validation $R_{\mathrm{tot}}$ 29.72\% $\rightarrow$ 21.25\% (-8.5~pp); per-atom MAE improved (0.0033 $\rightarrow$ 0.0032~eV).
  \item \textbf{Planar CGCNN:} validation $R_{\mathrm{tot}}$ 36.42\% $\rightarrow$ 32.77\% (-3.6~pp).
  \item \textbf{Planar Transformer:} validation $R_{\mathrm{tot}}$ 45.11\% $\rightarrow$ 46.46\% (+1.4~pp); $\lambda$ increased $0.005 \rightarrow 0.01$ per sweep.
  \item \textbf{Point all crystals (train+val):} CGCNN $R_{\mathrm{tot}}$ median 18.36\% $\rightarrow$ 51.22\% (+32.9~pp) on the full delivery set (train crystals dominate $n$); validation-only trend is the fair generalization read.
  \item \textbf{Caveat:} Point cells have many configs with $|\Delta E_{\mathrm{true}}|\approx 0$; absolute eV errors can look large while $R_{\mathrm{tot}}$ is the fair net-energy metric. Training val $R_{\mathrm{tot}}$ for point CGCNN rose because checkpoint target switched to full-cell.
  \item \textbf{Bottom line:} Mixed results. Point Transformer and planar metrics show small improvements or flat validation $R_{\mathrm{tot}}$; point CGCNN validation $R_{\mathrm{tot}}$ did not beat the prior $k=8$ graph-loss delivery on this split. Per-atom MAE remains excellent ($\sim 0.003$~eV on point validation).
\end{itemize}
